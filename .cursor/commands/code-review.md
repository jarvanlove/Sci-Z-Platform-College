# 代码审查清单

## 概述

全面的代码审查清单，用于确保代码质量、安全性、性能与可维护性（后期扩展性）。

## 审查类别

### 功能性

- [ ] 代码实现预期功能
- [ ] 已处理边界情况
- [ ] 错误处理恰当
- [ ] 无明显 bug 或逻辑错误

### 代码质量

- [ ] 代码可读性好且结构清晰
- [ ] 函数简洁且职责单一
- [ ] 变量命名具有描述性
- [ ] 无重复代码
- [ ] 遵循项目规范

### 代码性能

- [ ] 无多余计算、重复请求或明显 N+1 查询
- [ ] 大数据/列表考虑分页、懒加载或虚拟滚动
- [ ] 接口/函数无阻塞主流程的同步耗时操作（必要时异步或拆分）
- [ ] 资源（连接、句柄、订阅）有释放或防泄漏

### 可维护性与扩展性

- [ ] 模块/组件职责清晰，便于后续拆分或替换
- [ ] 配置、常量、枚举集中管理，便于修改与扩展
- [ ] 新增能力时无需大改现有代码（依赖抽象、接口或配置扩展）
- [ ] 关键逻辑有注释或文档，便于他人接手

### 安全性

- [ ] 无明显安全漏洞
- [ ] 已实现输入验证
- [ ] 敏感数据处理得当
- [ ] 无硬编码密钥
