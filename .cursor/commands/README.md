# Commands 目录说明

本目录存放 **Cursor 斜杠命令** 定义。用户在输入框输入 `/` 可选择并触发对应命令，由 Agent 按照命令中的步骤与要求执行（如代码审查、运行测试并修复失败）。

---

## 当前命令

| 文件               | 命令（示例）   | 说明                                                                                                                                       |
| ------------------ | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **code-review.md** | `/code-review` | 代码审查清单：按功能性、代码质量、性能、可维护性与扩展性、安全性等维度审查代码，输出勾选项与改进建议。可与 `skills/code-review` 配合使用。 |
| **run-tests.md**   | `/run-tests`   | 运行完整测试套件并系统性修复失败：执行测试、分析失败类型与优先级、逐项修复并复测，确保测试通过。                                           |

---

## 使用方式

1. 在 Composer 或 Chat 输入框中输入 **`/`**。
2. 在列表中选择对应命令（如 Code Review、Run Tests）。
3. 可选：在命令后追加说明或文件路径（视 Cursor 对命令参数的支持而定）。
4. Agent 会按该命令的「步骤」与「审查类别/要求」执行并回复。

---

## 命令文件格式

每个命令为一个 Markdown 文件，通常包含：

- **标题**：命令名称（会出现在 `/` 列表中）。
- **概述**：该命令的目的与适用场景。
- **步骤** 或 **审查类别**：Agent 执行时的具体步骤或检查清单（列表、勾选项等）。

在 `.cursor/commands/` 下新增 `.md` 文件即可注册新命令，Cursor 会扫描本目录并加入斜杠菜单。
