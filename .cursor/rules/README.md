# Rules 目录说明

本目录存放 **Cursor 通用规则**（`.mdc`），在对话与编辑时由 Cursor 按配置自动或按路径/引用加载，约束编码、文档与 Git 行为。

---

## 规则文件列表

| 文件                             | 说明                                                               | 生效方式                                                                      |
| -------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| **general-coding-standards.mdc** | 通用编码标准与最佳实践（代码质量、注释、提交格式），适用于前后端。 | **始终生效**（`alwaysApply: true`）                                           |
| **documentation-standards.mdc**  | 文档编写标准：Markdown 规范、结构、渐进式编写、元数据与专业输出。  | 路径匹配 `**/*.md`、`**/*.mdx`、`**/README*`、`**/doc/**` 时生效；也可 @ 引用 |
| **git-workflow.mdc**             | Git 工作流与分支管理（分支命名、提交类型约定）。                   | 不始终生效；涉及 Git 时易被带入，或通过 @ 引用                                |

---

## 生效时机说明

- **alwaysApply: true**：每次对话与编辑都会带入，无需 @。
- **alwaysApply: false 且无 globs**：Cursor 按对话相关性选择性加载；需要时可在输入框 **@**.cursor/rules/xxx.mdc 显式引用。
- **globs 配置**：当编辑/生成的文件路径匹配 glob 时自动应用；也可 @ 引用。

---

## 与子项目规则的关系

- 前端：`sci-z-web/.cursor/rules/` 下为 Vue/前端相关规则。
- 后端：`sci-z-server/.cursor/rules/` 下为 Java/DDD 相关规则。
- 本目录规则为**通用**，优先级高于子项目 CLAUDE.md、低于用户级 Rules 与根 CLAUDE.md（见 `.cursor/README.md` 配置优先级）。
