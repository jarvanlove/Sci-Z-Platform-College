# AgentBackendServices 快速开始指南

## 📦 第一步：安装依赖到本地仓库

```bash
cd AgentBackendServices
mvn clean install
```

安装成功后，会在本地 Maven 仓库生成：
- `~/.m2/repository/com/Server/AgentBackendServices/0.0.1-SNAPSHOT/AgentBackendServices-0.0.1-SNAPSHOT.jar`
- `~/.m2/repository/com/Server/AgentBackendServices/0.0.1-SNAPSHOT/AgentBackendServices-0.0.1-SNAPSHOT-sources.jar`

## 🔧 第二步：在目标项目中添加依赖

在目标项目的 `pom.xml` 中添加：

```xml
<dependencies>
    <!-- AgentBackendServices 依赖包 -->
    <dependency>
        <groupId>com.Server</groupId>
        <artifactId>AgentBackendServices</artifactId>
        <version>0.0.1-SNAPSHOT</version>
    </dependency>
</dependencies>
```

## ⚙️ 第三步：配置属性（可选）

如果使用 Dify 相关服务，在 `application.yml` 中配置：

```yaml
dify:
  api:
    base-url: https://api.dify.ai/v1
    timeout: 30000
```

## 💻 第四步：使用 Service

### 示例 1：使用 DifyApiService

```java
package com.yourproject.service;

import com.server.agentbackendservices.modules.dify.service.DifyApiService;
import com.server.agentbackendservices.modules.dify.dto.DifyChatbotAppRequest;
import com.server.agentbackendservices.modules.dify.dto.DifyChatbotAppResponse;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.ResponseEntity;
import org.springframework.stereotype.Service;

@Service
public class MyService {
    
    @Autowired
    private DifyApiService difyApiService;
    
    public void createChatbot() {
        DifyChatbotAppRequest request = new DifyChatbotAppRequest();
        request.setName("我的 Chatbot");
        request.setUserId(1L);
        request.setResourceId("resource-123");
        request.setKeyType("dataset");
        
        ResponseEntity<DifyChatbotAppResponse> response = 
            difyApiService.createChatbotApp(request);
        
        if (response.getStatusCode().is2xxSuccessful()) {
            DifyChatbotAppResponse app = response.getBody();
            System.out.println("Chatbot ID: " + app.getId());
        }
    }
}
```

### 示例 2：使用 DifyApiKeyService

```java
package com.yourproject.service;

import com.server.agentbackendservices.modules.dify.service.DifyApiKeyService;
import com.server.agentbackendservices.modules.dify.entity.DifyApiKey;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class MyService {
    
    @Autowired
    private DifyApiKeyService difyApiKeyService;
    
    public void manageApiKey() {
        // 获取 API Key
        String apiKey = difyApiKeyService.getApiKey(1L, "resource-123", "dataset");
        System.out.println("API Key: " + apiKey);
        
        // 保存 API Key
        DifyApiKey key = difyApiKeyService.saveOrUpdateApiKey(
            1L, 
            "resource-123", 
            "dataset", 
            "app-xxx-api-key",
            "我的密钥",
            "用于知识库访问",
            "admin"
        );
    }
}
```

### 示例 3：使用 AuthService

```java
package com.yourproject.service;

import com.server.agentbackendservices.modules.auth.service.AuthService;
import com.server.agentbackendservices.modules.auth.dto.LoginRequest;
import com.server.agentbackendservices.modules.auth.dto.LoginResponse;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class MyService {
    
    @Autowired
    private AuthService authService;
    
    public void login() {
        LoginRequest request = new LoginRequest();
        request.setUsername("admin");
        request.setPassword("password");
        
        LoginResponse response = authService.login(request);
        if (response != null) {
            System.out.println("登录成功，Token: " + response.getToken());
        }
    }
}
```

## ✅ 验证安装

启动目标项目，如果看到以下日志，说明依赖包已成功加载：

```
[INFO] Auto-configuration 'AgentBackendServicesAutoConfiguration' matched
```

或者在代码中测试：

```java
@SpringBootTest
class DependencyTest {
    
    @Autowired
    private DifyApiService difyApiService;
    
    @Test
    void testDependencyLoaded() {
        assertNotNull(difyApiService, "DifyApiService 应该被自动注入");
    }
}
```
