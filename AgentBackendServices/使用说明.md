# AgentBackendServices 依赖包使用说明

## 📦 项目简介

`AgentBackendServices` 是一个可复用的 Maven 依赖包，提供了 Dify API 调用、用户认证、权限管理等核心服务。其他项目可以直接引入此依赖，使用其中提供的 Service 方法。

## 🚀 安装依赖

### 方式一：安装到本地 Maven 仓库

```bash
cd AgentBackendServices
mvn clean install
```

安装成功后，依赖会安装到本地 Maven 仓库（`~/.m2/repository/com/Server/AgentBackendServices/0.0.1-SNAPSHOT/`）

### 方式二：安装到私有 Maven 仓库

如果需要部署到私有 Maven 仓库（如 Nexus、Artifactory），需要配置 `pom.xml` 的 `<distributionManagement>` 节点，然后执行：

```bash
mvn clean deploy
```

## 📝 在其他项目中使用

### 1. 添加 Maven 依赖

在目标项目的 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.Server</groupId>
    <artifactId>AgentBackendServices</artifactId>
    <version>0.0.1-SNAPSHOT</version>
</dependency>
```

### 2. 配置自动扫描（可选）

如果目标项目的主类不在 `com.server.agentbackendservices` 包下，需要确保 Spring Boot 能扫描到依赖包中的组件。

**方式一：在主类上添加组件扫描**

```java
@SpringBootApplication
@ComponentScan(basePackages = {
    "com.yourproject",  // 你的项目包
    "com.server.agentbackendservices.modules"  // 依赖包
})
@MapperScan(basePackages = {
    "com.yourproject.mapper",  // 你的 Mapper
    "com.server.agentbackendservices.modules.**.mapper"  // 依赖包的 Mapper
})
public class YourApplication {
    public static void main(String[] args) {
        SpringApplication.run(YourApplication.class, args);
    }
}
```

**方式二：依赖包已配置自动配置类，Spring Boot 会自动加载（推荐）**

依赖包已包含自动配置类 `AgentBackendServicesAutoConfiguration`，Spring Boot 会自动扫描并注册所有 Service、Config、Util 等组件，无需额外配置。

### 3. 配置必要的属性

在 `application.yml` 或 `application.properties` 中配置必要的属性：

```yaml
# Dify 配置（如果使用 Dify 相关服务）
dify:
  api:
    base-url: https://api.dify.ai/v1
    timeout: 30000

# Sa-Token 配置（如果使用认证服务）
sa-token:
  token-name: satoken
  timeout: 2592000
  token-prefix: Bearer
```

### 4. 使用 Service 方法

#### 使用 DifyApiService

```java
import com.server.agentbackendservices.modules.dify.service.DifyApiService;
import com.server.agentbackendservices.modules.dify.dto.DifyChatbotAppRequest;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.ResponseEntity;

@Service
public class YourService {
    
    @Autowired
    private DifyApiService difyApiService;
    
    public void createChatbot() {
        DifyChatbotAppRequest request = new DifyChatbotAppRequest();
        request.setName("我的 Chatbot");
        request.setUserId(1L);
        request.setResourceId("resource-123");
        request.setKeyType("dataset");
        
        ResponseEntity<DifyChatbotAppResponse> response = 
            difyApiService.createChatbotApp(request);
        
        if (response.getStatusCode().is2xxSuccessful()) {
            DifyChatbotAppResponse app = response.getBody();
            System.out.println("Chatbot 创建成功: " + app.getId());
        }
    }
}
```

## 📚 可用的 Service 列表

### Dify 相关服务

- **DifyApiService**: Dify API 调用服务
  - `createChatbotApp()` - 创建 Chatbot 应用
  - `updateChatbotModelConfig()` - 更新模型配置
  - `sendChatbotMessage()` - 发送对话消息
  - `sendChatbotMessageStream()` - 流式对话
  - `createDataset()` - 创建知识库
  - `uploadFile()` - 上传文件
  - `runWorkflow()` - 运行工作流
  - 更多方法请查看源码

- **DifyApiKeyService**: API Key 管理服务
  - `getApiKey()` - 获取 API Key
  - `saveOrUpdateApiKey()` - 保存或更新 API Key
  - `getUserApiKeys()` - 获取用户所有密钥
  - `getUserApiKeysByType()` - 按类型获取密钥
  - `deactivateApiKey()` - 停用密钥

### 认证相关服务

- **AuthService**: 认证服务
  - `login()` - 用户登录
  - `logout()` - 用户登出
  - `refreshToken()` - 刷新令牌
  - `getCurrentUser()` - 获取当前用户
  - `isLogin()` - 检查登录状态
  - `getCurrentUserId()` - 获取当前用户ID

- **UserService**: 用户服务
  - 继承自 `BaseService<User>`，提供基础的 CRUD 操作

### 通用服务

- **BaseService**: 基础服务接口
  - 提供通用的 CRUD 操作方法

## 🔧 配置说明

### 必需配置

如果使用 Dify 相关服务，需要配置：

```yaml
dify:
  api:
    base-url: https://api.dify.ai/v1  # Dify API 基础地址
    timeout: 30000  # 请求超时时间（毫秒）
```

### 可选配置

如果使用认证服务，需要配置 Sa-Token：

```yaml
sa-token:
  token-name: satoken
  timeout: 2592000
  token-prefix: Bearer
  jwt-secret-key: your-secret-key
```

如果使用数据库相关功能，需要配置数据源：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/your_database
    username: your_username
    password: your_password
    driver-class-name: org.postgresql.Driver
```

## 🐛 常见问题

### 1. Service 无法注入

**问题**：`@Autowired` 注入 Service 时报错 `NoSuchBeanDefinitionException`

**解决**：
- 确保主类能扫描到依赖包的组件（已配置自动配置类，通常无需额外配置）
- 检查 `application.yml` 中的配置是否正确
- 确保依赖包已正确安装到 Maven 仓库

### 2. Mapper 无法扫描

**问题**：MyBatis Mapper 无法找到

**解决**：
- 依赖包已配置 `@MapperScan`，会自动扫描所有 Mapper
- 如果仍有问题，在主类上添加 `@MapperScan` 注解

### 3. 配置属性不生效

**问题**：Dify 配置不生效

**解决**：
- 检查 `application.yml` 中的配置路径是否正确
- 确保配置类 `DifyConfig` 被正确加载（自动配置类已处理）
