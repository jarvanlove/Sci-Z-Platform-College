# Sci-Z 平台部署文档

## 📋 项目概述

Sci-Z 高校科研项目管理平台是一个前后端分离的智能化科研项目全生命周期管理系统。

- **后端项目**: `sci-z-server` (Java 21 + Spring Boot 3.2.5)
- **前端项目**: `sci-z-web` (Vue 3 + Vite)
- **后端端口**: 8808
- **前端开发端口**: 8707

---

## 🎯 部署环境说明

### 公司服务器环境

- **操作系统**: Windows Server
- **Docker**: Windows Docker Desktop
- **Java**: 8 (系统已有，但项目需要 Java 21)
- **Nginx**: 已安装

### 客户服务器环境

- **操作系统**: Linux
- **Docker**: 可选
- **Nginx**: 已安装

---

## 📦 环境要求

### 后端依赖

- **JDK 21** (LTS, 必须)
- **Maven 3.9+**
- **PostgreSQL 14+**
- **Redis 7.x**
- **Apache Kafka 3.x** (可选，用于领域事件)
- **MinIO** (对象存储)

### 前端依赖

- **Node.js 18+** (推荐 Node.js 20)
- **npm 9+** 或 **yarn 1.22+**

---

## 🚀 部署方案选择

### 方案一: Docker 部署 (推荐)

适用于已有 Docker 环境的服务器，部署简单，环境隔离。

### 方案二: 传统部署

直接在服务器上安装依赖并运行，适合需要精细控制的场景。

---

## 📝 方案一: Docker 部署

### 1. 准备工作

#### 1.1 创建项目目录结构

**Windows 服务器:**

```powershell
# 创建项目根目录
New-Item -ItemType Directory -Path "D:\Sci-Z-Platform" -Force

# 创建子目录
New-Item -ItemType Directory -Path "docker", "backend", "frontend", "data\postgres", "data\redis", "data\minio", "logs" -Force
```

**Linux 服务器:**

```bash
# 创建项目根目录
mkdir -p /opt/sci-z-platform/{docker,backend,frontend,data/{postgres,redis,minio},logs}
cd /opt/sci-z-platform
```

#### 1.2 准备 Docker Compose 文件

创建 `docker/docker-compose.yml`:

```yaml
version: "3.8"

services:
  # PostgreSQL 数据库
  postgres:
    image: postgres:15-alpine
    container_name: sci-z-postgres
    environment:
      POSTGRES_DB: sciz_platform
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${DB_PASSWORD:-ChangeMe123!}
      PGDATA: /var/lib/postgresql/data/pgdata
    volumes:
      - ../data/postgres:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    networks:
      - sci-z-network
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis 缓存
  redis:
    image: redis:7-alpine
    container_name: sci-z-redis
    command: redis-server --requirepass ${REDIS_PASSWORD:-ChangeMe123!} --appendonly yes
    volumes:
      - ../data/redis:/data
    ports:
      - "6379:6379"
    networks:
      - sci-z-network
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "redis-cli", "--raw", "incr", "ping"]
      interval: 10s
      timeout: 3s
      retries: 5

  minio:
    image: minio/minio:latest
    container_name: sci-z-minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_ACCESS_KEY:-minioadmin}
      MINIO_ROOT_PASSWORD: ${MINIO_SECRET_KEY:-minioadmin123}
    volumes:
      - ../data/minio:/data
    ports:
      - "9000:9000" # API 端口
      - "9001:9001" # 控制台端口
    networks:
      - sci-z-network
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"]
      interval: 30s
      timeout: 20s
      retries: 3

  # Kafka (可选，如果不需要领域事件可以注释掉)
  # zookeeper:
  #   image: confluentinc/cp-zookeeper:latest
  #   container_name: sci-z-zookeeper
  #   environment:
  #     ZOOKEEPER_CLIENT_PORT: 2181
  #     ZOOKEEPER_TICK_TIME: 2000
  #   networks:
  #     - sci-z-network
  #   restart: unless-stopped
  #
  # kafka:
  #   image: confluentinc/cp-kafka:latest
  #   container_name: sci-z-kafka
  #   depends_on:
  #     - zookeeper
  #   environment:
  #     KAFKA_BROKER_ID: 1
  #     KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
  #     KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://localhost:9092
  #     KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
  #   ports:
  #     - "9092:9092"
  #   networks:
  #     - sci-z-network
  #   restart: unless-stopped

  # 后端服务 (需要先构建镜像)
  backend:
    build:
      context: ../backend
      dockerfile: Dockerfile
    container_name: sci-z-backend
    environment:
      SPRING_PROFILES_ACTIVE: prod
      DB_HOST: postgres
      DB_PORT: 5432
      DB_NAME: sciz_platform
      DB_USERNAME: postgres

      DIFY_API_KEY: ${DIFY_API_KEY:-}
```

#### 1.3 创建后端 Dockerfile

创建 `backend/Dockerfile`:

```dockerfile
# 使用多阶段构建
# 阶段1: 构建
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app

# 复制 pom.xml 并下载依赖 (利用 Docker 缓存)
COPY pom.xml .
RUN mvn dependency:go-offline -B

# 复制源代码并构建
COPY src ./src
RUN mvn clean package -DskipTests -B

# 阶段2: 运行
FROM eclipse-temurin:21-jre-alpine
WORKDIR /app

# 创建非 root 用户
RUN addgroup -S spring && adduser -S spring -G spring
USER spring:spring

# 复制构建好的 JAR 文件
COPY --from=build /app/target/sci-z-server-*.jar app.jar

# 暴露端口
EXPOSE 8808

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --start-period=60s --retries=3 \
  CMD wget --no-verbose --tries=1 --spider http://localhost:8808/actuator/health || exit 1

# 启动应用
ENTRYPOINT ["java", \
  "-Xms512m", \
  "-Xmx2048m", \
  "-XX:+UseG1GC", \
  "-XX:MaxGCPauseMillis=200", \
  "-Djava.security.egd=file:/dev/./urandom", \
  "-Dspring.profiles.active=${SPRING_PROFILES_ACTIVE:-prod}", \
  "-jar", \
  "app.jar"]
```

#### 1.4 创建前端 Dockerfile

创建 `frontend/Dockerfile`:

```dockerfile
# 阶段1: 构建
FROM node:20-alpine AS build
WORKDIR /app

# 复制 package 文件
COPY package*.json ./
RUN npm ci --only=production

# 复制源代码并构建
COPY . .
RUN npm run build

# 阶段2: Nginx 服务
FROM nginx:alpine
WORKDIR /usr/share/nginx/html

# 删除默认文件
RUN rm -rf ./*

# 复制构建产物
COPY --from=build /app/dist .

# 复制 Nginx 配置
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

创建 `frontend/nginx.conf`:

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss application/json application/javascript;

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # API 代理
    location /api/ {
        proxy_pass http://backend:8808;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持 (如果需要)
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 健康检查
    location /health {
        access_log off;
        return 200 "healthy\n";
        add_header Content-Type text/plain;
    }
}
```

**安装 Redis:**

```bash
# Ubuntu/Debian
sudo apt install redis-server -y
sudo systemctl start redis-server
```

**安装 MinIO:**

```bash
# 下载 MinIO
cd /opt
sudo wget https://dl.min.io/server/minio/release/linux-amd64/minio
sudo chmod +x minio
sudo mv minio /usr/local/bin/

# 创建数据目录和用户
sudo useradd -r -s /bin/false minio
sudo mkdir -p /data/minio
sudo chown minio:minio /data/minio

# 创建 systemd 服务
sudo tee /etc/systemd/system/minio.service > /dev/null <<EOF
[Unit]
Description=MinIO Object Storage
After=network.target

[Service]
Type=simple
User=minio
Group=minio
Environment="MINIO_ROOT_USER=minioadmin"
Environment="MINIO_ROOT_PASSWORD=minioadmin123"
ExecStart=/usr/local/bin/minio server /data/minio --console-address ":9001"
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl start minio
sudo systemctl enable minio
```

#### 3.2 配置 Nginx

**Windows Nginx 配置:**

创建 `C:\nginx\conf\sci-z-platform.conf`:

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或使用 IP

    # 前端静态文件
    root D:/Sci-Z-Platform/frontend/dist;
    index index.html;

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss application/json application/javascript;

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # API 代理
    location /api/ {
        proxy_pass http://localhost:8808;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 健康检查
    location /health {
        access_log off;
        return 200 "healthy\n";
        add_header Content-Type text/plain;
    }
}
```

## ⚠️ 常见问题

### 1. 后端启动失败

**问题: Java 版本不匹配**

```bash
# 检查 Java 版本
java -version

# 确保使用 JDK 21
# Windows: 检查 JAVA_HOME 环境变量
# Linux: 使用 update-alternatives 切换 Java 版本
```

**问题: 端口被占用**

```bash
# Windows
netstat -ano | findstr :8808
taskkill /PID <进程ID> /F

# Linux
sudo lsof -i :8808
sudo kill -9 <进程ID>
```

**问题: 数据库连接失败**

- 检查 PostgreSQL 服务是否启动
- 检查数据库用户名密码是否正确
- 检查防火墙是否开放 5432 端口

### 2. 前端访问问题

**问题: 404 错误**

- 检查 Nginx 配置中的 `root` 路径是否正确
- 检查 `try_files` 配置是否正确
- 检查文件权限

**问题: API 请求失败**

- 检查 Nginx 代理配置
- 检查后端服务是否正常运行
- 检查 CORS 配置

### 3. 数据库问题

**问题: 表不存在**

```sql
-- 重新执行初始化脚本
\i /path/to/init_all_tables.sql
```

**问题: 连接数过多**

```sql
-- 查看当前连接数
SELECT count(*) FROM pg_stat_activity;

-- 修改 PostgreSQL 配置增加最大连接数
-- 编辑 postgresql.conf: max_connections = 200
```

### 4. Redis 问题

**问题: 连接失败**

```bash
# 检查 Redis 服务状态
# Windows: 检查服务是否启动
# Linux: sudo systemctl status redis

# 检查密码配置
redis-cli -a your_password ping
```

### 5. MinIO 问题

**问题: 文件上传失败**

- 检查 MinIO 服务是否正常运行
- 检查 bucket 是否存在
- 检查访问密钥是否正确
- 检查网络连接
